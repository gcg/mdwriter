## Steps

Run everything from the repo root. Start every shell with `export JAVA_HOME="$(/usr/libexec/java_home -v 21)"`
(never Homebrew's JDK 27, README rule 12). Set `ADB=~/Library/Android/sdk/platform-tools/adb` and
`BT=~/Library/Android/sdk/build-tools/36.0.0`.

1. **Preflight.** `git status --porcelain` must print only `?? plans/`. Check
   `ls -d ~/.gradle/wrapper/dists/gradle-8.7-bin/*/gradle-8.7/bin/gradle` (the cached Gradle 8.7) and
   `/usr/libexec/java_home -v 21 --failfast`. If either is missing, use the fallbacks in step 3.
2. **Verbatim copies.** Use `cp`. Do not retype these files: tabs and comment placement matter (HARD RULE 14).
   ```bash
   cp plans/reference/gitignore .gitignore
   cp plans/reference/editorconfig .editorconfig
   cp plans/reference/Makefile Makefile
   cmp Makefile plans/reference/Makefile && cmp .gitignore plans/reference/gitignore && cmp .editorconfig plans/reference/editorconfig
   ```
3. **Gradle wrapper.** Follow research/toolchain.md §4 exactly. Do this **before** copying the real build files,
   because Gradle 8.7 cannot load AGP 9.3.3.
   ```bash
   echo 'rootProject.name = "mdwriter"' > settings.gradle.kts          # temporary; step 4 overwrites it
   SHA=acd53f1edaf02f1a8ff99879f8a34b302661a057d9b063ae9e35b552f804d20a  # gradle-9.7.1-bin.zip
   G87=$(ls -d ~/.gradle/wrapper/dists/gradle-8.7-bin/*/gradle-8.7 | head -n 1)
   "$G87/bin/gradle" --no-daemon -q wrapper --gradle-version 9.7.1 --distribution-type bin --gradle-distribution-sha256-sum "$SHA"
   ./gradlew -q wrapper --gradle-version 9.7.1 --distribution-type bin --gradle-distribution-sha256-sum "$SHA"   # 2nd run refreshes the jar
   shasum -a 256 gradle/wrapper/gradle-wrapper.jar   # MUST be 7a9ce74cff467ca1bf60a4fcd9f05185acceda4d0f382434d393e17864262c5d
   ```
   Compare `gradle/wrapper/gradle-wrapper.properties` with the verified content in toolchain.md §4 (lines 159–170).
   Fallbacks, in order, if the cached 8.7 is gone or a run fails (toolchain.md §4 lines 180–183):
   (a) Hand-write that properties file. Then
   `curl -fsSLo gradle/wrapper/gradle-wrapper.jar https://raw.githubusercontent.com/gradle/gradle/v9.7.1/gradle/wrapper/gradle-wrapper.jar`,
   and fetch `gradlew` and `gradlew.bat` from the same tag path (`chmod +x gradlew`). Verify the jar sha.
   (b) Download `gradle-9.7.1-bin.zip`, check it against `$SHA`, and run its `bin/gradle wrapper …` once.
   Record whichever fallback you used in STATUS "Deviations".
4. **Build files.** Copy them verbatim. `cp -R` merges into the existing `gradle/` directory:
   ```bash
   cp -R plans/reference/build/. .
   for f in settings.gradle.kts build.gradle.kts gradle.properties gradle/libs.versions.toml app/build.gradle.kts core/markdown/build.gradle.kts; do cmp "plans/reference/build/$f" "$f" || echo "DIFF $f"; done
   ```
5. **SDK location + daemon JVM.** `make local.properties` creates `local.properties` (`sdk.dir=…`, git-ignored).
   Then run `./gradlew -q updateDaemonJvm --jvm-version=21`. It works only now, because the foojay plugin is in
   `settings.gradle.kts`; without it the error is "Toolchain download repositories have not been configured".
   `./gradlew --version` must print `Gradle 9.7.1` and
   `Daemon JVM: Compatible with Java 21 … (from gradle/gradle-daemon-jvm.properties)`. Do not hand-edit the file.
   Fallback if `updateDaemonJvm` cannot reach the foojay API (it needs network): write the file with the single
   line `toolchainVersion=21`, then re-check `--version` and record the deviation.
6. **`:core:markdown` placeholder.** Create `ModuleInfo.kt` and `ModuleInfoTest.kt` (Reference code §A).
7. **`:app` sources.** Create the manifest, `MdWriterApp`, `AppContainer`, `util/Dispatchers.kt`, `util/Log.kt`,
   `MainActivity`, both `strings.xml`, `themes.xml` and `keepRules/app.keep` (Reference code §B–§F).
8. **README.md** (Reference code §G). Paste the install section verbatim:
   `sed -n '386,445p' plans/research/build.md` prints exactly the text between the four-backtick fences, from
   `## Install on your phone` to the `no JDK 17-26 found` row. Put it in the README unchanged.
9. **Format + check.** Run `make format`, then `make check`. `check` = `spotlessCheck lint test :app:assembleRelease`.
   Two lint warnings are expected and fine: `MissingApplicationIcon` (T02 adds the icon) and `DataExtractionRules`
   (T11 adds it). Lint errors are not fine. `make doctor` must run without errors.
10. **Emulator, debug build.** `make emulator` (a no-op if one is running), then `make devices` to get the serial.
    Use it as `DEVICE=` everywhere; the commands below assume `emulator-5554`. Run
    `make install-debug DEVICE=emulator-5554`, take a screenshot and look at it (Verification commands).
11. **Emulator, release build with a throwaway key.** Run `make install DEVICE=emulator-5554 KEYSTORE_DIR=/tmp/mdwriter-agent-key`.
    The `keystore` prerequisite creates the throwaway key in `/tmp/mdwriter-agent-key/`. Then check the versionCode,
    the signer, `aapt2` badging/permissions/manifest, the keep rule, and configuration-cache reuse (acceptance 7–13).
12. **Remove the agent-signed release from the emulator** so the user's later real-key `make install` does not hit
    `INSTALL_FAILED_UPDATE_INCOMPATIBLE`: run `make uninstall CONFIRM=yes DEVICE=emulator-5554`. **Emulator only.**
    This is the one explicit uninstall this plan asks for; never run it against a phone (HARD RULE 13). Keep the
    debug app installed.
13. **STATUS + commit.** Append the T01 entry to `plans/STATUS.md` (template in that file). Then check
    `git status --porcelain`: no `local.properties`, `.gradle/`, `.kotlin/`, `build/`, `*.jks` or `keystore.properties`
    may appear. Finally `git add -A && git commit -m "T01: project bootstrap, Makefile, installable skeleton"`.
    The commit includes `plans/` unchanged except `STATUS.md`.

import android.app.Application

import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.SupervisorJob

/**
 * Manual DI root (01-architecture §5). ViewModels read it via `(application as MdWriterApp).container`.
 * Later tasks add: settings, positions (T11/T19), internalStore, recovery (T10), library, documents, autosave (T11+).

class AppContainer(val app: Application) {
    /** Outlives every ViewModel: saves and flushes run here so a finishing activity never drops a write. */
    val applicationScope: CoroutineScope = CoroutineScope(SupervisorJob() + Dispatchers.Default)

    val dispatchers: AppDispatchers =
        AppDispatchers(io = Dispatchers.IO, default = Dispatchers.Default, main = Dispatchers.Main)
}

### D. `util/Log.kt` (sketch)
```kotlin
package dev.mdwriter.util

import dev.mdwriter.BuildConfig

/**
 * The only logging entry point: import dev.mdwriter.util.Log, never android.util.Log.
 * d/i are debug-only (and R8 strips android.util.Log.v/d from release anyway, see keepRules/app.keep).
 * Note: plain JVM unit tests (no Robolectric) cannot call android.util.Log ("Method ... not mocked"),
 * so pure classes that are tested on the JVM must not log.
 */
object Log {
    inline fun d(tag: String, message: () -> String) {
        if (BuildConfig.DEBUG) android.util.Log.d(tag, message())
    }

    inline fun i(tag: String, message: () -> String) {
        if (BuildConfig.DEBUG) android.util.Log.i(tag, message())
    }

    fun w(tag: String, message: String, error: Throwable? = null) {
        android.util.Log.w(tag, message, error)
    }

    fun e(tag: String, message: String, error: Throwable? = null) {
        android.util.Log.e(tag, message, error)
    }
}
```
`app/src/main/keepRules/app.keep` (AGP ≥ 9.3 picks up `src/main/keepRules/*.keep` automatically; research/toolchain.md
§8.5, line 603):
```
# Strip verbose/debug logging from release builds (dev.mdwriter.util.Log is also gated on BuildConfig.DEBUG).
-assumenosideeffects class android.util.Log {
    public static int v(...);
    public static int d(...);
}
```

## Pitfalls
- **Wrapper order.** Gradle 8.7 must only ever see the one-line `settings.gradle.kts`. With the real build files it
  tries to load AGP 9.3.3 (needs Gradle ≥ 9.5) and fails. Run the wrapper task **twice**: the first run leaves
  8.7's jar (`cb0da675…`, 43,453 B), the second writes 9.7.1's (`7a9ce74c…`, 47,505 B).
- **JDK.** Gradle 9.7.1 runs only on JVM 17–26. Homebrew's `openjdk` is 27. Always export JBR 21 for raw
  `./gradlew`; the Makefile finds it on its own.
- **`updateDaemonJvm` without foojay** fails with "Toolchain download repositories have not been configured". It
  needs the real `settings.gradle.kts` (step 4) and `local.properties` (step 5; otherwise "SDK location not found").
- **Tabs / inline comments.** Copy the Makefile and `.gitignore` with `cp`. An editor that expands tabs breaks every
  recipe (`*** missing separator`). A `# comment` after a `.gitignore` pattern becomes part of the pattern
  (HARD RULE 14, build.md §6.1).
- **Never apply `org.jetbrains.kotlin.android`** (AGP 9 has built-in Kotlin; the build fails). No AppCompat/MDC; the
  theme parent is the platform `android:Theme.Material.Light.NoActionBar` (HARD RULE 1).
- **Keep `applicationId = "dev.mdwriter"` a literal on one line.** The Makefile `sed`-parses it (build.md §5.2 #3).
  You are copying the file verbatim, so just don't touch it.
- **No permissions.** Do not add `INTERNET` or anything else (HARD RULE 1). The only `uses-permission` in the APK
  must be androidx.core's `…DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` (platform.md §10.7).
- **Signing safety (README rules 6, 13).** Never run `make install`, `make apk` or `make keystore` without
  `KEYSTORE_DIR=/tmp/mdwriter-agent-key`. Never create, read or write `~/.config/mdwriter/`. Never install onto,
  uninstall from, or run adb against a physical phone: always pass `DEVICE=emulator-…`. `make check` builds a release
  APK too, and without a key it falls back to the debug key with a loud `!!!` warning. That is expected.
- **Configuration cache.** Any change in a `-P` value (e.g. `mdwriter.keystore`) invalidates the entry
  (build.md V8). Run the two `assembleRelease` calls with **identical** arguments. The debug-key fallback banner is
  not printed on a cache hit (build.md §2.3).
- **versionName before the first commit** is `0.1.0`, because `git rev-parse` finds no HEAD. After the commit it is
  `0.1.0+<sha8>`. Both are correct.
- **Expected lint warnings** (not errors): `MissingApplicationIcon` (fixed in T02) and `DataExtractionRules`
  (fixed in T11). Don't "fix" them here by adding those tasks' files.
- **Gradle 9 fails a test task that has test classes but discovers no tests.** Keep the one real `@Test` in
  `ModuleInfoTest`. The `testRuntimeOnly(junit-platform-launcher)` line in the verified build file is required.
- **`make uninstall` is emulator-only and explicit.** Step 12 exists because the throwaway-key release would block the
  user's real-key install on the same emulator. Do not uninstall `dev.mdwriter.debug`.
- **Robolectric/Compose UI tests are not part of T01.** The first `:app` Robolectric test (T02) downloads nothing,
  because `android-all-instrumented` 17 is already in `~/.m2`.
